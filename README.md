#  PrintPal

**PrintPal** is a campus-focused digital printing platform that connects students with nearby print shops, allowing users to upload documents, customize print settings, pay online, and collect their prints without waiting in queues.

---

##  Problem Statement

Students often waste time waiting in long queues at print shops, face unclear pricing, and have limited options for placing print orders remotely. PrintPal simplifies the entire printing process through a seamless digital platform.

---

##  Solution

PrintPal enables users to:
- Upload documents securely
- Customize print settings
- Select nearby print shops
- Pay digitally
- Track order status in real time
- Receive notifications when prints are ready

Print shop owners receive orders through a dedicated seller dashboard, allowing them to manage and update order statuses efficiently.
